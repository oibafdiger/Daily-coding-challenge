# Daily Coding Challenge

Tägliche Programmieraufgaben aus dem freeCodeCamp-Programm – konsequent gelöst und versioniert.

Jede Datei entspricht einer Aufgabe und ist nach dem Schema  
`[Nummer]-[Aufgabenname]-[Datum].py` benannt.

---

## Ziel

Algorithmen und Problemlösung durch tägliche Praxis schärfen.  
Kein Framework, kein Overhead – reines Python, klare Logik.

---

## Beispielaufgaben

| Challenge | Thema |
|---|---|
| #213 – Word Length Converter | String-Verarbeitung |
| #214 – Domino Chain Validator | Listenlogik & Validierung |
| #224 – Coffee Roaster Detector | Bedingungslogik |
| #226 – Exam Count | Zählalgorithmen |
| #227 – Cooldown Time | Zeitberechnungen |
| #232 – Due Date | Datumslogik |
